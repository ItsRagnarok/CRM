# Bundled fonts

The original variable fonts are hosted locally through `next/font/local` so builds do not depend on Google Fonts CSS parsing or downloads. They include Romanian diacritics. Existing CSS variable names are preserved.

Downloaded from the official Google Fonts repository:

- `inter-variable.ttf`: https://github.com/google/fonts/blob/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf
- `unbounded-variable.ttf`: https://github.com/google/fonts/blob/main/ofl/unbounded/Unbounded%5Bwght%5D.ttf
- `jetbrains-mono-variable.ttf`: https://github.com/google/fonts/blob/main/ofl/jetbrainsmono/JetBrainsMono%5Bwght%5D.ttf

Each font's SIL Open Font License and copyright notice are included alongside the files. The files are unmodified upstream font binaries.
